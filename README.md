# DecodeLabs Project 1 – Data Cleaning & Preparation

## 📌 Project Overview

This project focuses on cleaning and preparing a raw e-commerce dataset for analysis using **Microsoft Excel Power Query**.

The goal was to transform the raw dataset into a clean, consistent, and analysis-ready dataset while maintaining data integrity.

## 🛠️ Tools Used

- Microsoft Excel
- Power Query
- GitHub

## 🔍 Data Cleaning Process

The following data-cleaning steps were performed:

1. Promoted the first row to column headers
2. Reviewed and corrected data types
3. Checked for duplicate records
4. Checked for missing and blank values
5. Standardized coupon codes
6. Replaced blank coupon codes with `NO COUPON`
7. Standardized text values for consistency
8. Verified the final dataset for errors
9. Loaded the cleaned dataset for analysis

## ✅ Data Quality Checks

The final dataset was reviewed for:

- Duplicate records
- Missing values
- Blank values
- Data type inconsistencies
- Errors
- Inconsistent text formatting

The cleaned dataset was successfully prepared for further analysis.
